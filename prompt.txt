[MINDMAP_GENERATION]
Create a comprehensive, fact-rich mind map about {{topic}}.

Use this Markdown hierarchy:
# Matching Mind Map Title
## Branch 1
### Sub Branch A
### Sub Branch B
## Branch 2

Requirements:
- Use one line per text element, with # characters to express hierarchy.
- Use 2-3 levels of depth unless the topic clearly needs more.
- Include concrete facts and useful detail, not only category labels.
- Avoid generic branches such as Overview, Introduction, or Conclusion.
- Use the language of the topic.
- Use a concise title and at least three top-level branches.

Return only this JSON object:

- The target node must be one # heading.
- Add up to five ## or ### child nodes in total.
- Use detailed, factual, concrete sub-branches.
- Write in the language used by the hierarchy path.

Markdown, existing node notes and research, and a question.

ancestors themselves. Use previous notes to keep the research coherent and answer
